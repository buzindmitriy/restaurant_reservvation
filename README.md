# Restaurant Reservation System

Сайт для бронирования столиков в ресторане с использованием Django и Bootstrap.

## Особенности

- Интерактивная форма бронирования
- Админка для управления бронированиями
- Адаптивный дизайн с Bootstrap
- Контейнеризация с Docker

## Требования

- Python 3.9+
- Docker и Docker Compose
- PostgreSQL
